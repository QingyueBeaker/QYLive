# 合规说明（法律风险闭环）

本文件是项目发布前必须保留的合规基线，任何 PR 都不得突破以下边界。

## 1. 项目性质

- 完全开源（MIT）、完全非营利、独立第三方通用工具。
- 与哔哩哔哩（Bilibili）及其关联主体**无任何从属、合作、赞助或官方关联**，未使用其商标作为自身品牌。
- 程序不包含任何平台名称之外的平台特定逻辑；所有代码路径对任意标准 RTMP 服务端同样适用。

## 2. 明确不做的事（技术上也不可能做）

| 禁止项 | 现状 |
| --- | --- |
| 自动获取推流密钥 | 无。密钥只能由用户从键盘输入（`streamKey` 输入框） |
| JS 注入 / DOM 修改 / 自动点击 | 无。内嵌页面由 WebView2 直接加载官方 URL，程序不向后注入任何脚本 |
| 抓包 / 接口解析 / 私有 API | 无。代码中不存在 HTTP 客户端调用平台接口 |
| 自动登录 / 记住密码 | 无。程序不保存任何账号或密码 |
| 弹幕 / 礼物 / 自动互动 / 批量开播 | 无。不存在相应功能与依赖 |
| 绕过风控 / 伪造设备指纹 | 无。推流使用标准 RTMP，服务端可见的行为与 OBS 一致 |
| 版权内容抓取 | 无。程序只上传用户本机的屏幕与音频 |

## 3. 数据与隐私

- 无遥测、无崩溃上报、无云端配置、无账号体系。
- 程序只在用户点击“开始推流”后，与**用户自己填写的** RTMP 服务器地址建立 TCP 连接。
- 日志仅输出到 stderr（控制台），不落盘、不压缩、不上传。
- WebView2 的浏览器缓存/角色态由系统 WebView2 管理，属于浏览器正常行为；程序不读取、不导出、不上传这些数据。

## 4. 用户责任

使用者应自行确保：

1. 直播内容不侵犯他人著作权、肖像权、隐私权；
2. 遵守所在平台的服务条款、直播规范与当地法律法规；
3. 所推流的游戏/软件画面已获得必要授权（游戏厂商通常对“个人直播”有明确允许范围）。
